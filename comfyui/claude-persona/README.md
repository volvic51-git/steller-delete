## 2. ファイル

- `claude_persona_workflow.json` … ComfyUIの画面にドラッグ＆ドロップして読み込む
- `claude_persona_api.json` … API（`POST /prompt`）用の形式
- `build.py` … 上の2つを生成するスクリプト（プロンプトや設定はここで変更）

## 3. 使い方

1. SDXL系のアニメ向けチェックポイントを `ComfyUI/models/checkpoints/` に置く
   （想定は `animagine-xl-4.0.safetensors`。Illustrious系、NoobAI系でも動きます）
2. ワークフローを読み込み、Load Checkpointのファイル名を手元のモデル名に合わせる
3. Queue Prompt（832×1216、28ステップ、CFG 5、euler_ancestral、4枚生成）

APIから実行する場合:

```bash
python3 -c "import json;print(json.dumps({'prompt':json.load(open('claude_persona_api.json'))}))" \
  | curl -s -X POST http://127.0.0.1:8188/prompt -H 'Content-Type: application/json' -d @-
```

## 4. 調整のヒント

- 実写寄りにしたい → チェックポイントをJuggernaut XLなどに変え、タグを文章形式に書き換える
- 全身を描きたい → `upper body` を `full body, standing` に変える
- メガネなし版 → `round glasses, thin frame glasses` を削除し、ネガティブに `glasses` を追加する
